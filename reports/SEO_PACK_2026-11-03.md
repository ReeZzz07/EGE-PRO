## Технический SEO

| Проверка | Статус | Факт live |
|---|---|---|
| HTTPS | **норма** | `http://` → **308** на `https://ege-tutor.ru/` |
| Один хост | **норма** | `www` → **301** на apex |
| robots.txt | **норма** | `Allow: /`, Sitemap своего хоста; коммерция не в Disallow |
| sitemap.xml | **норма** | 29 URL, все `ege-tutor.ru`; есть `/`, `/tariffs`, `/parents`, `/contacts`, `/blog/*`, 4× `/ege/*` |
| Viewport / 200 | **норма** | коммерческие URL 200 |
| Canonical | **норма** | на свой хост; у `/diagnostic` нет (и ок: noindex) |
| Уникальные title/H1 | **норма** | дублей в выборке нет |
| Битые внутр. ссылки (выборка `/`, `/blog`) | **норма** | не найдены |
| Тяжёлые картинки | **не хватает данных** | в обходе 0 по HEAD; CWV не выдумываем |
| `/diagnostic` H1 | **норма** | H1 «Диагностика уровня по предмету», `noindex, follow` (кабинет) |
| Длинные blog title | **норма** | обрезаны ≈60 симв. с «…»; H1 полный |
| Description `/ege/*` | **норма** (после правки) | `trimText(lead, 160)` |
| Description `/parents` | **норма** (после правки) | укорочен + H1 про 30 дней |
| Title `/tariffs`, `/contacts` | **норма** (после правки) | усилены по пакету |
| H1 `/blog` bot vs SPA | **норма** (после правки) | bot = `blogIndex.h1` |
| Город «Россия» в H1 | **не относится** | онлайн-сервис; см. `AUDIT_FIXES` — не пихать в H1 |
| tel: / NAP / 2ГИС | **не относится** | SaaS без офлайн-точки |
| `/diagnostic` в индекс | **норма** | noindex — так и должно |

## Контентный SEO

| Проверка | Статус | Комментарий |
|---|---|---|
| Услуга понятна с главной | **норма** | тренажёр + ИИ + ФИПИ-формат + цифры банка |
| «Город» | **норма** (для модели) | «вся Россия» на contacts/оферта/футер; не локальная витрина |
| Страницы `/ege/*` | **норма** | общий каркас, но уникальные H1/title, число заданий, темы раздела |
| Пустой каталог предметов | **не относится** | лендинги только у 4 предметов (`landingSubjects`); остальные — в продукте без SEO-URL |
| Гарантии балла | **норма** | явных «гарантируем 100» в выборке нет |
| H1 `/parents` | **норма** (после правки) | «понятной оплатой на 30 дней» |
| Семантика расширения предметов | **гипотеза** | отдельные URL для физики/англ/… — только если готовы уникальные тексты, не копипаст |
