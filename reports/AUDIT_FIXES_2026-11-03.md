# Разбор аудита ege-tutor.ru_2026-11-03 — что сделано / что шум

## Сделано в коде (деплой нужен)

| Пункт аудита | Решение |
|---|---|
| Нет H1 на `/diagnostic` | Prerender H1 через `/__private` + `X-Private-Path` (Caddy vars) |
| Нет заявки / tel: на главной | Не tel: (SaaS). mailto + явный блок «оставить заявку» на `/` (bot HTML), футер, `/contacts` |
| NAP / карты / город «Россия» в H1 | **Не** пихаем город в H1. Факты «вся Россия» + реквизиты/оферта на contacts; 2ГИС не нужен (нет офлайн-точки) |
| Директ рано без заявки | Канал заявки = диагностика + форма/mailto. Paid по-прежнему PAUSED до confirm |
| Длинные blog title | `<title>` обрезается до ~60 симв.; H1 полный |
| Нет FAQ/JSON-LD на tariffs/contacts/blog | FAQ + FAQPage LD добавлены |
| Нет JSON-LD на oferta/privacy | WebPage + breadcrumbs |
| ИНН в обходе | Блок реквизитов всегда (из админки или ссылка на оферту) |
| «метит на 100 баллов» в футере | Смягчено |
| Риск «лучший» в статьях | Правка контента в БД (SQL ниже) |

## Шум аудита (не делаем)

- `tel:` / телефон как обязательный канал
- «город Россия» в H1 коммерческих страниц
- Ссылки на 2ГИС / Яндекс.Карты без физического адреса
- Ссылки на VK/IG/TenChat/Max/OK/Rutube без реальных URL (заведёте каналы → добавим)
- FAQ на каждой legal-странице сверх WebPage
- Full SSR всей платформы включая `/app/*` (см. ответ в чате)

## SQL на прод (контент блога)

```sql
-- смягчить «лучший» в опубликованных статьях (пример)
UPDATE public.blog_articles
SET content = replace(content, 'лучший', 'удачный'),
    updated_at = now()
WHERE is_published = true
  AND content ILIKE '%лучший%';
```
